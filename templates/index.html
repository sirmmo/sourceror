LLM (opzionale) non configurato

Sourceror funziona senza LLM. Se configurato, viene usato solo dove le API non bastano: riformulare un'affermazione in query di ricerca, e valutare se una fonte candidata sostiene davvero quella specifica affermazione. Endpoint compatibile OpenAI (OpenRouter, OpenAI, LiteLLM, vLLM locale…).
